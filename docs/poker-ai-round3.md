# 德州人机第三轮：未知对手与多人桌验证

## 目标和边界

不读取对手私牌、牌堆或内部性格标签，使用已完成牌局的公开下注行动推断倾向。评估净筹码收益，不把拿第一或单手胜率当成目标。生产入口保持旧策略，实验参数未开启，本轮不发布。

## 第一步：公开行为校准

用旧策略九种性格各400手自然对局，共3600手，校准入池率、翻前加注率、面对下注弃牌率、翻后加注率和大尺寸下注比例。推断只使用过去12手公开记录，不使用摊牌手牌、胜负、盈利或未来行动。

采用九种风格的概率混合，并限制观察置信度：12手历史只占50%权重，另一半仍为通用模型。没有观察时完整退回通用模型。它是实验性概率推断，不是对真人贴标签，也不是求解器或语言模型训练。

## 第二步：独立预测验证

使用1000个独立合法后期位置（转牌500，河牌500），每个位置另生成12手过去的公开观察。

|模型|预测损失（越低越好）|Brier误差（越低越好）|
|---|---:|---:|
|通用模型|0.655610|0.393482|
|公开行为推断|0.659649|0.395643|
|已知类型对照|0.597161|0.364216|

**12手行为推断未改善预测。** 当前验证针对旧人机家族，不能推断真人表现。短历史中有效翻后行动少、相近风格难区分；自然对局的行为频率也不一定能代表强制构造的后期测试位置。

## 第三步：收益初测与性能调整

初测未知类型对手，每类500组交换座位，每版本1000手。完整新策略包含公开范围与后期搜索，因此它与旧策略的差距不能全部归因于风格推断。松跟注型增益+138.27 BB/100，紧凶+30.11，施压型-21.75，价值型+36.71；除松跟注外区间均包含0。

四人初测250组，四个座位轮换，每版本1000手，增益-63.64 BB/100，95%区间[-159.34,+32.07]，没有通过。四人对手仍在场时只更新范围；后期搜索仅用于剩两人的简单局面，未做完整多人树。

双人初测部分时间与预测验证同时运行，可能影响24ms软搜索截止，故只作开发诊断，不作为最终性能证据。

发现混合多个风格会重复计算相同概率，新增有界512项缓存；缓存返回独立数组，避免调用方修改后污染后续结果。缓存不修改动作模型的概率，但可改变超时回退次数。

## 第四步：冻结版本复核

缓存后的双人冻结版本：每类1000组、交换座位，每版本2000手，四类合计16000手评价对局（另有过去12手的观察对局）。

|对手|增益 BB/100|95%区间|旧/新盈利块|
|---|---:|---|---|
|松跟注|+23.82|[-47.23, +94.87]|15/50 → 15/50|
|紧凶|+25.89|[-18.03, +69.82]|35/50 → 29/50|
|诈唬施压|+34.45|[-36.45, +105.35]|21/50 → 23/50|
|价值猎手|+30.72|[-10.75, +72.19]|26/50 → 32/50|

四组平均增益均为正，但所有区间均包含0，没有确认稳定收益优势。两个对手组的盈利块次数没有增加，其中紧凶组下降；不能承诺人类玩家更难赢钱。观察到的新策略决策平均耗时约2.40–7.42ms，p95约8.28–31.86ms；24ms仅是搜索软预算，不是整次决策硬上限。

四人冻结复核500组，四座位轮换，每版本2000手，共4000手评价对局：旧策略 -20.70 BB/100，新策略 -37.29 BB/100，增益 -16.60，95%区间 [-78.87, +45.68]。盈利块由12/25降为9/25。平均决策耗时4.34ms、p95 24.52ms。仍未通过多人收益验证；不能把负向点估计说成已经确认的退化。

冻结版本双人和四人合计20000手评价对局，观察对局另算。没有根据复核结果继续调整参数，再用同一批数据宣称通过。

复核单独执行，不同时运行其它模拟或构建任务。

## 第五步：保留生产策略

未把行为推断接入实际玩家记录、房间快照或服务器决策。所有线上默认仍为legacy范围、lookahead=false。新增测试检查公开信息边界、概率归一化、历史窗口、范围缓存隔离、缓存上限和数组隔离，连同原测试共23项通过。

人工20组块的盈利次数只用于比较重置筹码基准，不是真人连续20手赢钱概率。置信区间以同牌、交换座位的组为单位；多个对手、多个版本试验未经多重比较校正，不据此单独选择好结果上线。

## 下一步的取舍

本轮不推广九类风格推断。先改进公开行动的条件化统计：区分位置、下注尺寸和局面，积累足够有效面对下注的观察，而非只按过去手数提高置信度。自然行为频率与后期位置预测有分布差异，需要专门验证。再单独比较「通用模型」与「行为模型」的收益，隔离范围更新和搜索的贡献。

激进型复核平均增益+34.45 BB/100，但区间跨0，不能据此宣称再加注防守已修好。完整多人规划、实际连续筹码会话与真人样本仍未实现，本轮没有将这些当作已完成。
