# 德州人机：第一轮优化与训练记录

第二轮已完成，最新结果见 [第二轮记录](poker-ai-round2.md)。以下为保留的第一轮历史记录，部分实现和训练入口已在第二轮更新。

本轮已完成实验实现、概率校准、独立对局验证和性能检查。**尚未证明稳定优于旧策略，暂不替换线上人机。** `server/rooms.mjs` 仍调用旧默认策略；新范围和搜索只在实验脚本显式开启。默认行为与 v127 的固定对照逐项一致。

## 1. 固定基准，明确目标

保留 v127 策略于 `tests/fixtures/poker-strategy-v127.mjs`。以净赢筹码（BB/100手）为主指标，同时记录赢筹码手数比例、固定手数分组的盈利比例、回撤和耗时。

每组用同一副牌打两次、交换新旧策略座位。独立的发牌与决策随机数防止策略改变后续发牌。每手重置100BB筹码，轮换九种性格。旧策略对自身的2000手检查得到0 BB/100手，确认座位抵消机制正常。置信区间按换座组计算；胜率不能取代筹码收益。

## 2. 更新公开信息范围

根据位置、历史行动、下注金额和当时公共牌，计算每种可能手牌的权重。历史翻牌行动只使用当时的三张牌，不能拿后来出现的转牌、河牌反推当时决策。真实对手底牌与牌堆均不读取。

第一版手工概率在2000手测试中为−24.10 BB/100手，搜索为−29.46。失败记录保留，没有删掉负结果。

## 3. 校准回应概率

独立模拟6000手旧策略对战，得到12123次行动。记录行动者自己的手牌特征、是否面对下注、底池赔率、位置和所选动作。对稀疏统计做平滑，得到弃牌／跟注／加注概率表。

这是从旧策略的模拟行动校准概率，不是CFR、不是真人数据，也不是调用语言模型。下注尺寸仍包含启发式约束。训练发牌与验证发牌独立。

校准后的独立2000手：范围版+13.45 BB/100手，搜索版+2.17；两者95%近似区间均包含0。

## 4. 单挑转牌、河牌行动搜索

限定仍在场的两名玩家且无全下或复杂边池。枚举当前合法弃牌、跟注／过牌、半池和满池等有限下注大小，模拟对手回应，并在转牌后抽样河牌和后续行动。

每个公开分支都对整个可能手牌范围评估，不能对每个假设的对手手牌单独选择最佳操作。对手弃牌、跟注或加注后，相应范围重新加权。已修正前后位过牌顺序与全下后不能再加注的边界。

限制：使用近似对手模型、有限河牌样本与有限再加注深度，并非完整求解整棵德州树。未将角色技能规则纳入实验搜索；生产技能局保持原样。

## 5. 控制成本，复测收益

范围缓存最多48项；相同手牌特征和概率查表复用。搜索采用24ms软预算，超时舍弃不完整搜索并回退；预算只针对搜索阶段，并非整个决策的硬上限。全下、多人仍在场、复杂边池继续走原决策。

最终较大测试10000手：+23.15 BB/100手，95%近似区间−0.71～+47.01；赢筹码手数比例49.97%，250个40手分组中127个盈利。分组与回撤是重置筹码模拟指标，不能当作真人连续打牌的赢钱概率。

四人桌初测1200手：+49.35 BB/100手，区间−29.04～+127.74。每个座位轮流放一个新策略，其余三个为旧策略，尚不足以证明多人优势。

性能优化后另一个独立2000手批次：−11.82 BB/100手，区间−60.41～+36.77。决策平均4.04ms、95分位29.12ms、最大44.40ms；旧策略平均0.91ms。较大批次使用优化前版本；软超时会随设备速度影响回退率，两批不可直接作纯性能配对比较。新增的边池守卫经回归测试确认。

## 结论与下一轮

14项策略、合法性、筹码守恒、隐藏信息隔离、缓存和回退测试通过，构建通过。正负批次交替，所有收益区间仍包含0，且新策略较耗时，因此本轮晋级门槛未通过。线上未发布或启用实验策略。

下一轮优先补充转牌／河牌训练样本，校准不同下注尺寸及再加注回应，并增加新发牌种子和松跟注、紧弃牌、激进对手的验证。需要稳定净收益优势和可接受耗时后，才适合考虑有限启用。
